- ## 标识符规则
	- JS 的标识符 (即 变量、函数等的名称) 可以使用如下字符：
		- letter ( `a-z` 、 `A-Z` )
		  logseq.order-list-type:: number
		- underscore ( `_` )
		  logseq.order-list-type:: number
		- dollar sign ( `$` )
		  logseq.order-list-type:: number
		- numeric ( `0-9` )
		  logseq.order-list-type:: number
		- 大部分特殊的 Unicode letters (如 `å` and `ü` )
		  logseq.order-list-type:: number
	- 其中，只有 letter 、underscore 和 dollar sign 可以放在开头。
