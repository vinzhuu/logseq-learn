- ## Xcode 是工具套件
	- 参考: [Apple Docs - Xcode 首页](https://developer.apple.com/documentation/xcode)
	- Xcode 是 **构建苹果平台应用程序 (Apps for Apple platforms)** 的工具套件.
	- 包含如下工具:
		- Device Hub : 管理模拟设备和物理设备.
		  logseq.order-list-type:: number
		- Icon Composer : 制作应用图标.
		  logseq.order-list-type:: number
		- Instruments : 分析应用性能.
		  logseq.order-list-type:: number
		- Reality Composer : 创建 3D 内容.
		  logseq.order-list-type:: number
		- Create ML : 训练自定义机器学习模型.
		  logseq.order-list-type:: number
		- Accessibility Inspector : 检查应用无障碍适配情况.
		  logseq.order-list-type:: number
		- Xcode Cloud : 构建, 测试 和 分发应用.
		  logseq.order-list-type:: number
