- ## GNU Classpath 作用
	- 为 JVM 和 Java 编译器 提供 **自由** 的 **核心类库 (core class libraries)** .
		- ==或许就是实现 [[Java SE API Specification]] 里的东西, 不过当时可能还没有 Java SE 的说法? ==
	- 当时 Java 还在 Sun Microsystems 手中, Sun Microsystems 开放了 standard class library 的源代码, 但使用的是 Sun Community Source License , 不属于 Free License .
