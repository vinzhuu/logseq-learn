- ## OpenSpec 是啥
	- OpenSpec 是一种面向 AI 编程助手的 **规范驱动开发方式 ( [[Spec-Driven Development]] )** .
- ## 各 Agent 如何集成 OpenSpec
	- 两种方式:
		- 安装为 `Skills` :
		  logseq.order-list-type:: number
			- 一般安装到 `.../skills/openspec-*/SKILL.md`
		- 安装为 `Commands` :
		  logseq.order-list-type:: number
			- 有些 Agent 支持安装 **斜杠命令** .
- ## OpenSpec CLI 是啥
	- 支持 OpenSpec 开发流程的 CLI 工具
		- 参见: [[OpenSpec CLI]]
- ## 工作原理
	- OpenSpec 产生的相关文档, 应和代码库放在一起, 并纳入版本管理.
