- ## 按 发酵程度 分类
	- | 茶类 | 发酵程度 | 典型茶叶 |
	  | ---- | ---- | ---- |
	  | **绿茶** | 不发酵 | 龙井、碧螺春、毛峰、信阳毛尖 |
	  | **白茶** | 微发酵 | 白毫银针、白牡丹、寿眉、贡眉 |
	  | **黄茶** | 轻发酵 | 君山银针、蒙顶黄芽、霍山黄芽 |
	  | **乌龙茶 / 青茶** | 半发酵 | 铁观音、大红袍、凤凰单丛、冻顶乌龙 |
	  | **红茶** | 全发酵 | 正山小种、祁门红茶、滇红、金骏眉 |
	  | **黑茶** | 后发酵 | 安化黑茶、六堡茶、茯砖茶 |
