- ## Bitwise
	- 参见: [[Bitwise]]
	- `~` : 按位取反.
	- `&` : 按位与.
	- `|` : 按位或.
	- `^` : 按位异或.
- ## Bit Shift
	- 参见: [[Bit Shift]]
	- `<<` : Signed Left Shift Operator
		- shifts a bit pattern to the left
	- `>>` : Signed Right Shift Operator
		- shifts a bit pattern to the right.
	- `>>>` : Unsigned Right Shift Operator
