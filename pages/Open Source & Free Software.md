- ## Open Source 源自 Free Software
	- 1983 年, Free Software 运动开始.
	- 1998 年, Free Software 社区中的一部分人分裂出去, 开始以 Open Source 的名义进行活动.
		- 一开始, 使用 Open Source 这个术语, 是为了避免人们对 Free 产生误解.
		- 但是很快, Open Source 就与一些 "与 Free Software 截然不同的哲学观点" 联系在了一起.

- ## Open Source 支持者们的观点
	- 一部分支持者认为, Open Source 是 "Free Software 的市场营销活动" :
		- 旨在, 强调软件的实际利益, 而不提 "是非对错", 以吸引企业高管.
	- 其它支持者, 则干脆拒绝 Free Software 倡导的价值观.
	- ==总之:==
		- 无论他们观点为何, 他们对 Open Source 的讨论, 并不关注 "是非对错" , 而只关注 **软件流行度和成功** .
		- 甚至少部分人, 将 **自由** 当成一个问题来讨论.
- ## Open Source 与 Free Software 的观念区别
	- ### 核心价值观
		- 如今, Open Source 与 Free Software 几乎描述的是同一类软件, 但它们代表了不同的价值观.
			- Free Software 的价值观: 尊重用户自由. (这是道德要求)
			- Open Source 的价值观: 让软件更好. (这是实用主义)
	- ### 对 Nonfree Software 的看法
		- Open Source 与 Free Software 对 Nonfree Software 的看法:
			- Free Software 不赞同 Nonfree Software:
				- Free Software 从道德角度出发, 认为 Nonfree Software 是一个社会问题.
				- 解决方案是: 停止使用 Nonfree Software , 并转向 Free Software
			- Open Source 也不赞同 Nonfree Software :
				- Open Source 从实用角度出发, 认为 Nonfree Software 是一种比较差的开发方式.
				- 解决方案是: 停止用 Nonfree Software 方式开发, 改用 Open Source 方式开发.
- ## Open Source 软件不一定 Free
	- Open Source 软件由如下类别组成:
		- 极大部分使用既属于 Open Source License 也属于 Free License 的 License , 且不存在 [[Tivoization]] 行为 (属于 Free Software).
		  logseq.order-list-type:: number
		- 极小部分使用既属于 Open Source License 也属于 Free License 的 License , 但存在 [[Tivoization]] 行为 (属于 Nonfree Software).
		  logseq.order-list-type:: number
			- 虽然仍符合 Open Source 标准, 但是 [[Tivoization]] 行为却违反 Free Software 精神.
				- 它虽然 **源码** 是 **自由的** , 但是 **可执行文件** 却 **不是自由的** .
			- 比如, 有 **许多安卓设备的操作系统** , 属于这一类.
		- 极小部分使用属于 Open Source License 但不属于 Free License 的 License (属于 Nonfree Software).
		  logseq.order-list-type:: number
	- ==所以总结就是:==
		- 几乎所有 Free Software 都符合 Open Source 标准 (可能存在例外).
		  logseq.order-list-type:: number
		- 而并非所有 Open Source 软件, 都是 Free Software.

- ## Open Source 比 Free Software 更容易被误解
	- Free Software 容易被理解为 `免费软件` , 但只要告诉他这里的 `Free` 是 `自由` 的意思, 就很容易澄清.
	- 而 Open Source 很容易被简单理解为 `你可以看源代码` / `source available` , 却没有那么容易说清楚, 因为它字面上看上去就是这个意思.
- ## Open Source & Free Software 与 GPL
	- GPL 属于 Open Source License 中的一种, GPL 也属于 Free License 中的一种.
		- ==实际上, 大部分 Open Source License 都属于 Free License .==
	- 所以:
		- Free Software 可以使用 GPL , 也可以不使用.
		- Open Source 可以使用 GPL , 也可以不使用.
- ## Open Source 一词被泛化
	- Open Source 一词, 由于被用于一些没有 **源代码** 的领域, 导致这个词进一步被误解.
		- 比如: 政府, 教育, 科学 等领域.
	- 在这些领域, Open Source 通常只是用来表示 **共享** 或 **透明** .
- ## Open Source 对 Free Software 的影响
	- Open Source 虽然客观上让许多企业和个人, 开始使用甚至开发 Free Software .
	- 但是, [[Richard Matthew Stallman]] 认为它阻碍了用户对 Free Software 的更深层次的理解, 没有教会他们去捍卫自己的自由.
		- RMS 还认为, 一切推广 Open 一词, 都倾向于掩盖 Free Software 运动的意义.
- ## FLOSS & FOSS
	- `FLOSS` 和 `FOSS` 都可以中立的表示 Free Software 或 Open Source Software .
	- 但 RMS 更建议使用 `FLOSS` (参见: [[FOSS]] )
		- FSF 当然两个都不使用, 因为他们不保持中立, 他们坚持 Free Software 的理念 .
