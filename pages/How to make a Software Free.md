- ## 方法一: 尽可能主动放弃 Software 的所有权利
	- 尽可能主动放弃 Software 的所有权利, 让公众获得类似 [[Public Domain]] 的使用自由 (比如使用 [[CC0]] )
	- 这种方法的弊端是:
		- 一些不愿意合作的人, 可能会在自己修改后, 将其作为 `Proprietary Software` 发布.
- ## 方法二: 给 Software 添加 Free License
	- 参见: [[Free License]]
