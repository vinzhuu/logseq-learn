- ## 性别相关属性
	- 生理性别 (Sex) : 
	  logseq.order-list-type:: number
		- 男 / 女 /[[间性人]]
	- 性别认同 (Gender Identity) : 
	  logseq.order-list-type:: number
		- 男 / 女 / 非二元 / 无性别
	- 性别表达 (Gender Expression) : 向外界呈现自己的方式
	  logseq.order-list-type:: number
	- 代词 (Pronouns)
	  logseq.order-list-type:: number
	- 性取向 (Sexual Orientation) :
	  logseq.order-list-type:: number
- ## LGBTQ+
	- `LGBTQ+` 描述的是 **性取向** 和 **性别认同** 的多样性.
- ## 软件开发相关
	- 一般的软件开发中, 一般来讲, 关注 **生理性别** 属性 即可, 可以给用户如下选项:
		- 男 (Male)
		  logseq.order-list-type:: number
		- 女 (Female)
		  logseq.order-list-type:: number
		- 非二元性别 (Non-binary)
		  logseq.order-list-type:: number
		- 不方便透露 (Prefer not to say)
		  logseq.order-list-type:: number
