- ## 如何产生本地临时文件
	- 大致有如下方式, 可以产生 **本地临时文件** (2026-08-19)
		- 可以看到, 一般字段名称就是 `tempXxxxPath` .
	- | 场景 | 接口 / 能力 | 返回的临时文件路径 |
	  | ---- | ---- | ---- |
	  | 用户主动选择 | `wx.chooseMedia()` | `tempFiles[].tempFilePath` |
	  |  | ~~`wx.chooseImage()`~~ | `tempFilePaths[]` |
	  |  | ~~`wx.chooseVideo()`~~ | `tempFilePath` |
	  |  | `wx.chooseMessageFile()` | `tempFiles[].path` |
	  | 下载文件 | `wx.downloadFile()` | `tempFilePath` |
	  |  | `wx.cloud.downloadFile()` | `tempFilePath` |
	  | 图片 / 视频处理 | `wx.compressImage()` | `tempFilePath` |
	  |  | `wx.compressVideo()` | `tempFilePath` |
	  |  | `wx.cropImage()` | `tempFilePath` |
	  |  | `wx.editImage()` | `tempFilePath` |
	  |  | `wx.openVideoEditor()` | `tempFilePath` / `tempThumbPath` |
	  | 拍照 / 录像 / 录音 | `CameraContext.takePhoto()` | `tempImagePath` |
	  |  | `CameraContext.stopRecord()` | `tempVideoPath` / `tempThumbPath` |
	  |  | `CameraContext.startRecord()` 的 `timeoutCallback` | `tempVideoPath` / `tempThumbPath` |
	  |  | `RecorderManager.onStop()` | `tempFilePath` |
	  |  | ~~`wx.startRecord()`~~ | `tempFilePath` |
	  | 截图 / 导出 | `wx.canvasToTempFilePath()` | `tempFilePath` |
	  |  | `LivePlayerContext.snapshot()` | `tempImagePath` |
	  |  | `LivePusherContext.snapshot()` | `tempImagePath` |
	  |  | `Snapshot.takeSnapshot()` | `tempFilePath` |
	  | 录制媒体内容 | `MediaRecorder` 的 `stop` 事件 | `tempFilePath` |
