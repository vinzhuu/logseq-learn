- ## Package Manager
	- Swift 官方包管理工具: [[SwiftPM]]
		- 新项目一般优先考虑 `SwiftPM`
	- Swift 社区包管理工具: [[CocoaPods]]
		- 有一些库可能只支持 `CocoaPods` .

	- 支持 SwiftPM 的 Package 的仓库: [[Swift Package Index]]

	- 提名成功后会展示在这里 : [Community Showcase](https://www.swift.org/packages/showcase.html)
