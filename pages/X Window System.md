## 什么是 X Window System
	- X Window System 也被简称为 X .
	- X Window System 是一个网络透明图形系统.
	- 它允许程序在 **远程计算机** 运行，但 **图形界面** 显示在 **本地计算机** .
		- 所谓 **网络透明** , 即 程序是否在远程运行, 对用户来说是“透明的” , 使用体验和本地运行一样.
- ## X Client 与 X Server
	- (下面没有写反)
	- **远程计算机** 被称为 **X Client** , 表示发送图形信息的客户端.
	- **本地计算机** 被称为 **X Server** , 表示显示图形信息的服务端.
		- Linux 一般自带 X Server 软件, 不用额外安装.
		- macOS 一般不自带 X Server 软件, 需要安装 (如 [[XQuartz]] ) .
		- Windows 一般不自带 X Server 软件, 需要安装.
