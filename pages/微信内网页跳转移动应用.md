- ## 方案
	- 微信提供的方案: 
	  logseq.order-list-type:: number
		- [[微信开放标签: wx-open-launch-app]]
	- 微信内网页直接使用 [[Deep Linking]]
	  logseq.order-list-type:: number
		- ==大部分 App 不可以使用 URL Scheme (除非在白名单内)==
	- 引导用户 "右上角用浏览器打开" .
	  logseq.order-list-type:: number
		- ==缺点: 增加用户操作流程, 需要再次在浏览器内打开 Web 页面.==
	- 接入腾讯应用宝, 由 **应用宝** 处理.
	  logseq.order-list-type:: number
		- 如果没安装 **应用宝** , 就是跳转到 **应用宝 Web 页面** 进行处理
		  logseq.order-list-type:: number
		- 如果安装了**应用宝** , 就是拉起 **应用宝 App** 进行处理.
		  logseq.order-list-type:: number
		- ==缺点: 接入较复杂.==
