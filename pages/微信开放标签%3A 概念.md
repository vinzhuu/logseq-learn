- ## 什么是微信开放标签
	- **微信开放标签** 是: **微信公众平台** 面向 **网页开发者** 提供的 **扩展标签集合** .
	- 使用它, 可以在 **微信内网页** 中, 安全便捷地调用 **微信或系统的能力** .
- ## 微信开放标签环境要求
	- ### 环境版本要求
		- 微信版本:
		  logseq.order-list-type:: number
			- `iOS/Android` : 7.0.12 及以上
			  logseq.order-list-type:: number
			- `鸿蒙` : 1.0.3 及以上.
			  logseq.order-list-type:: number
		- 系统版本:
		  logseq.order-list-type:: number
			- `iOS` : 10.3 及以上
			  logseq.order-list-type:: number
			- `Android` : 5.0 及以上
			  logseq.order-list-type:: number
		- JS-SDK 版本: 1.6.0 及以上.
		  logseq.order-list-type:: number
			- 对的, **微信开放标签** 依赖 [[微信 JS-SDK]]
	- ### iframe 限制
		- 使用 **开放标签** 的网页, 不可以作为 `iframe` 嵌入其它网页.
- ## 无法使用微信开放标签处理
	- ### WeixinOpenTagsError 事件
		- 如果无法使用 **微信开放标签** , `wx.config` 权限验证成功后, 会触发 `WeixinOpenTagsError` 事件告知开发者 **错误原因** .
			- **微信开放标签** 无法使用, 并不会影响 JS-SDK 的其他功能.
		- 监听 `WeixinOpenTagsError` 事件:
			- ``` js
			  document.addEventListener('WeixinOpenTagsError', function (e) {
			    console.error(e.detail.errMsg); // 无法使用开放标签的错误原因，需回退兼容。
			  });
			  ```
	- ### 回退兼容
		- 如果排查发现, 满足上述要求, 还是无法使用 **微信开放标签** , 可以在 `WeixinOpenTagsError` 监听器中, 做 **回退兼容** 处理.
		- 回退兼容建议:
			- `iOS`: iOS15 底层 WebKit 接口 发生变更, 微信版本 8.0.8 以下(不包括8.0.8) 无法使用开放标签.
			  logseq.order-list-type:: number
				- 可引导用户 **升级最新版本微信**  .
			- `Android` : 极少部分 Android 系统可能由于版本太低, 而不支持微信开放标签依赖的 [[Web Components]] 技术 , 从而无法使用开放标签.
			  logseq.order-list-type:: number
				- 可引导用户 **升级系统固件** .
