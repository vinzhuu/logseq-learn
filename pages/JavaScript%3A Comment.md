- ## Line Comments
	- ``` js
	  // single line comment
	  ```
- ## Block Comments
	- ``` js
	  /* This is a block comment */
	  
	  /* 
	   * this is a longer,
	   * multi-line comment
	   */
	  ```
	- Block Comments 中不能直接使用 `*/` ，需要进行转义，写为 `*\/` 。
	- ``` js
	  /* You can /* nest comments *\/ by escaping slashes */
	  ```
