- ## 单个主干: 主干 + 修饰
	- 所有英文句子, 都是由 `主干` + `修饰` 组成的.
	- ### 主干成分
		- 除了英语中有一些汉语中没有的句型 (比如 There be) :
			- 主干成分, 汉语与英语基本一致.
		- 参见: [[English Grammar/简单句]]
	- ### 修饰成分
		- 在汉语中, **修饰成分** 基本放在 **被修饰词** 前面.
			- eg: 这是一朵美丽的花.
			- eg: 这是一朵公园里的花.
		- 而在英语中:
			- **较短修饰成分** 通常放在 **被修饰词** 前面.
			  logseq.order-list-type:: number
				- eg: This is a beautiful flower.
			- **较长修饰成分** 通常放在 **被修饰词** 后面.
			  logseq.order-list-type:: number
				- eg: This is a flower (in the park).
				- ==这种 **较长的修饰成分** 是导致我们阅读困难的重要因素.==
	- ### 较短修饰成分
		- 包含 **形容词** 和 **副词** .
		- ==这通常不会是汉语母语者的阅读难点.==
	- ### 较长修饰成分 (四朵金花)
		- #### 介词短语: `介词 ... 名词`
			- `起止标识`: 从 **介词** 开始到 **名词** 终止.
			- eg: at school / on the table
		- #### 从句: `引导词 + 陈述句` (引导词有时可省略)
			- 一定从引导词开始 (有时可省略).
			- `终止标识` :
				- 到 **句尾** 终止:
				  logseq.order-list-type:: number
					- `eg` : LiHui is a teacher (who teaches English).
				- 到 **逗号** 终止:
				  logseq.order-list-type:: number
					- `eg` : (When I was young), I listened to the radio.
				- 到下一个 **修饰成分** 终止:
				  logseq.order-list-type:: number
					- `eg` : I will invite Yaoming (who was a top basketball player) (to Beijing).
				- 到下一个 **谓语动词** 终止:
				  logseq.order-list-type:: number
					- `eg` : Yaoming (who was a top basketball player) is studying in Shanghai.
		- #### 非谓语动词: `to do / doing / done`
			- 一定从`to do / doing / done` 开始 .
			- `终止标识` :
				- 到 **句尾** 终止:
				  logseq.order-list-type:: number
					- `eg` : LiHui is a teacher (teaching English).
				- 到 **逗号** 终止:
				  logseq.order-list-type:: number
					- `eg` : (To improve my English), I often chat with foreigners.
				- 到下一个 **修饰成分** 终止:
				  logseq.order-list-type:: number
					- `eg` : Jack walked in,(waving confidently) (to the audience).
				- 到 **谓语动词** 终止:
				  logseq.order-list-type:: number
					- `eg` : We,(singing a happy song) rode to school.
		- #### 时间: `看似名词, 却是表时间的状语`
			- eg: (Last week), I went (to the theatre) .
- ## 多个主干: 平行并列结构
	- ### 平行并列结构长啥样
		- 使用 **并列词** 连接 **两个及以上结构相同的成分** 的结构.
		- 并列词如下:
			- and、or、but
			  logseq.order-list-type:: number
			- as well as、not only...but also...、both...and...
			  logseq.order-list-type:: number
			- either...or.，neither...nor...
			  logseq.order-list-type:: number
	- ### 哪些成分可以并列
		- **名词并列**
		  logseq.order-list-type:: number
			- `Tom` and `Jerry` are friends.
		- **动词并列**
		  logseq.order-list-type:: number
			- With the Internet, people can not only `play` computer games but also `do` online shopping.
		- **修饰成分并列**
		  logseq.order-list-type:: number
			- **形容词并列**
			  logseq.order-list-type:: number
				- Mr. Smith is a `kind`, `patient` and `knowledgeable` English teacher.
			- **副词并列**
			  logseq.order-list-type:: number
				- You are supposed to answer the following questions `quickly` and `accurately`.
			- **介词短语并列**
			  logseq.order-list-type:: number
				- And that government `of the people`, `by the people` and `for the people` shall not perish from the earth.
			- **从句并列**
			  logseq.order-list-type:: number
				- I’ve finished reading the book `which is written by Mo Yan` and `which you lent me last month`.
			- **非谓语动词并列**
			  logseq.order-list-type:: number
				- `Singing` and `laughing`, we headed to the park.
		- **整句并列**
		  logseq.order-list-type:: number
			- `The children can go with us` or `they can stay at home`.
- ## 括号阅读法
	- ### 步骤
		- 可以通过如下步骤来阅读:
			- 预处理 (`四朵金花一并列` ):
			  logseq.order-list-type:: number
				- 将句子中的 **较长修饰成分 (四朵金花)** 用 **括号** 括起来.
				  logseq.order-list-type:: number
					- `eg`: **Li Hui is a teacher** (teaching English) (in Beijing) (which is the capital) (of China) .
					- ==注意: 不要根据句子成分, 画出括号套括号的情况 (因为这样分析起来比较麻烦).==
						- `eg`: **Li Hui is a teacher** {[teaching English (in Beijing)] [which is the capital (of China)]} .
						- 只要出现下一个金花, 就将上一个金花结束.
				- 将句子中的 **并列词** 用 **方括号** 括起来.
				  logseq.order-list-type:: number
			- 顺逻辑
			  logseq.order-list-type:: number
				- **主干成分** 直接读 (因为与中文几乎无异) .
				  logseq.order-list-type:: number
				- **较长修饰成分 (四朵金花)** 一截一截顺下来.
				  logseq.order-list-type:: number
				- 遇到 **并列词** , 可以先找到 **并列词后** 的那一项, 再返回去找 **并列词前** 的另一项.
				  logseq.order-list-type:: number
					- 因为 **并列词后** 的那一项显然比较好确定, 而  **并列词前** 的那一项可以找与  **并列词后** 的那项 **结构相同** 的成分.
			- 调语序
			  logseq.order-list-type:: number
				- 若要翻译成 **汉语** , 还要调整语序: 将 **后置的修饰成分** 放到 **被修饰词** 前面.
	- ### 较长修饰成分怎么顺?
		- 停顿法: 每个括号停顿下  (母语者大概也是这样一截截说话的)
		  logseq.order-list-type:: number
		- 提问法: 利用括号里的第一个单词进行 "自问自答" (母语者大概也是这样一截截思考的)
		  logseq.order-list-type:: number
			- 遇到 doing , 问 "干什么呢?" .
			  logseq.order-list-type:: number
			- 遇到 done , 问 "怎么样的?"
			  logseq.order-list-type:: number
			- 遇到 时间 , 问 "什么时候?"
			  logseq.order-list-type:: number
			- 遇到 其它词 , 根据这个词的本意提问.
			  logseq.order-list-type:: number
