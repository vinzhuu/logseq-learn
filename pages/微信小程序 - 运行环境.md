- ## 小程序在各平台的运行环境
	- | **运行平台** | **逻辑层** | **视图层** |
	  | ---- | ---- | ---- |
	  | iOS/iPadOS/macOS 微信客户端 | JavaScriptCore | WKWebView |
	  | Android 微信客户端 | V8 | XWeb (微信基于 Mobile Chromium 内核自研的引擎) |
	  | Windows 微信客户端 | Chromium 内核 | Chromium 内核 |
	  | [[WMPF]] | 估计得看设备的系统 | 估计得看设备的系统 |
	  | 微信开发者工具 | [[NW.js]] | Chromium WebView |
- ## 运行环境差异
	- ### WXSS 渲染表现
		- WXSS 渲染表现不一致.
		- 对于 "某些运行环境, 无法识别某些样式, 但有等价写法" 的情况:
			- 可以开启 **微信开发者工具**  的 `样式补全` 选项;
			- 开启后,  **微信开发者工具** 在编译时, 会自动补充各个运行环境的等价样式, 让各个运行环境都能识别.
			- ==例子:==
				- 如果我们写 `display: flex;` , 会被补全成:
					- ``` css
					  display: -webkit-flex;
					  display: flex;
					  ```
				- 因为, 旧版 [[WebKit]] (WKWebView 的底层引擎)只认得 `display: -webkit-flex;` .
		- 而对于 "各个运行环境, 对统一样式的实际实现不同" 的情况:
			- 无法通过 `样式补全` 来解决.
	- ### 对 ECMAScript 语法 和 API 的支持情况
		- 不同版本的不同运行环境, 对 ECMAScript 标准的支持情况不同.
		- #### 语法
			- 为了处理某些运行环境, 不支持某些 语法 的情况 (即 有些低版本运行环境只支持 `ES5` 版本, 写 `ES6` 语法会报错):
				- 可以开启 **微信开发者工具**  的 `将 JS 代码编译成 ES5` 选项;
				- 开启后, **微信开发者工具** 在编译时, 会使用 [[Babel]] , 将 ES6 代码编译成符合 ES5 标准的代码.
			- ==具体参见: [将 JS 代码编译成 ES5](https://developers.weixin.qq.com/miniprogram/dev/devtools/codecompile.html#%E5%B0%86-JS-%E4%BB%A3%E7%A0%81%E7%BC%96%E8%AF%91%E6%88%90-ES5)==
		- #### API
			- 为了处理某些运行环境, 不支持某些 API 的情况:
				- 小程序基础库, 内置了 [[core-js]] 这个 [[Polyfill]] .
				- `core-js` 可以将各个运行环境中缺失的标准 API 补齐.
			- 以下 API 在 **部分低版本客户端** 中没有被 **Polyfill** , 应尽量避免使用:
				- `Proxy` 对象
		- #### 如何判断当前环境需要哪些 Polyfill & 代码转换目标
			- 通过 **小程序基础库最低版本** 得到.
				- ==在 [小程序管理页](https://mp.weixin.qq.com/) **设置 - 基本设置 - 基础库最低版本设置** 中设置==
			- **小程序基础库最低版本**  -> **微信客户端最低版本** -> **操作系统最低版本** -> **运行环境最低版本** -> 需要哪些 Polyfill & 代码转换目标
			- 获取指定基础库版本的 [[Browserslist]] 信息 和 Polyfill 信息: [miniprogram-compat](https://github.com/wechat-miniprogram/miniprogram-compat)
- ## 运行环境的局限
	- ### 所有运行环境的局限
		- 小程序不支持动态执行 JS 代码, 即:
			- 不支持调用 `eval` 函数执行 JS 代码.
			  logseq.order-list-type:: number
				- `eval` 函数属于 `ECMAScript` 标准的一部分, 接收一个字符串, 作为 JS 代码执行.
			- 不支持使用 `new Function` 语法创建函数, `new Function('return this')` 除外.
			  logseq.order-list-type:: number
	- ### JavaScriptCore 的局限
		- `JavaScriptCore` 无法开启 **JIT 编译** , 所以, 同等条件下, 性能会明显比其他运行环境差.
	- ### 微信开发者工具的局限
		- 开发者工具 **仅供调试** 使用, 最终的表现 **以 微信客户端 为准** .
