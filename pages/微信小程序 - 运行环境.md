- ## 各平台的运行环境
	- | **运行平台** | **逻辑层** | **视图层** |
	  | ---- | ---- | ---- |
	  | iOS/iPadOS/macOS 微信客户端 | JavaScriptCore | WKWebView |
	  | Android 微信客户端 | V8 | XWeb (微信基于 Mobile Chromium 内核自研的引擎) |
	  | Windows 微信客户端 | Chromium 内核 | Chromium 内核 |
	  | [[WMPF]] | 估计得看设备的系统 | 估计得看设备的系统 |
	  | 微信开发者工具 | [[NW.js]] | Chromium WebView |
- ## 运行环境差异
	- ### JavaScript 语法和 API
		- 对 JavaScript 语法和 API 的支持不一致.
	- ### WXSS 渲染
		- WXSS 渲染表现不一致.
	- ### 微信开发者工具的局限
		- 开发者工具 **仅供调试** 使用, 最终的表现 **以 微信客户端 为准** .
	- ### JavaScriptCore 的局限
		- `JavaScriptCore` 无法开启 **JIT 编译** , 所以, 同等条件下, 性能会明显比其他运行环境差.
