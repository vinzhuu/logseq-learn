- 直译: `可能性是：……?`
- 含义: `很可能...`
- 其他形式：
	- 口语中一般省略 `the` 。
	  logseq.order-list-type:: number
- 例句:
	- | 形式 | 结构 |
	  | ---- | ---- | ---- |
	  | **The odds are that it will rain tomorrow.​** | `that it will rain tomorrow` 是表语从句 |
	  | **Odds are it will rain tomorrow.​** | 可看作省略 `that` 的表语从句结构，也可理解为惯用表达 |
	  | **Odds are, it will rain tomorrow.​** | `Odds are` 是插入语，后面是独立主句 |
- 摘录:
	- > Whatever the application you are working on is, `odds are that` you will need to store and process data in memory at some point.
