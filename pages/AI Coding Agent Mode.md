- ## AI Coding Mode
	- 参考: [TRAE - SOLO Coder](https://docs.trae.ai/ide/solo-coder?_lang=zh)
	- 目前 AI Agent 写代码有如下几种模式:
		- 普通 模式: 用户提个需求, Agent 分析需求, 然后直接开干.
		  logseq.order-list-type:: number
		- Plan 模式: 用户提个需求, Agent 分析需求, 然后生成一份规划文档, 用户确认后按照文档开干.
		  logseq.order-list-type:: number
		- Spec 模式: 用户提个需求, Agent 分析需求, 然后生成三份文档:  **大纲 (spec.md)、 任务列表 (tasks.md) 和 验收清单 (checklist.md)**, 用户确认后按照文档开干.
		  logseq.order-list-type:: number
