- ## 基础库与运行环境
	- 小程序基础库 = 统一封装的 API + 小程序框架 + 兼容层 .
		- ==同一版本的小程序基础库, 不管其底层运行环境如何, 提供的 API 都是一致的.==
	- 小程序运行环境 = 小程序真正执行的底座.
		- 参见: [[微信小程序 - 运行环境]]
	- 关系大概如下:
		- ``` zsh
		  小程序代码
		      ↓
		  小程序基础库（API + 框架 + 兼容层）
		      ↓
		  小程序运行环境（JS 引擎 + 渲染引擎 + 系统能力）
		      ↓
		  操作系统（iOS / Android / Windows）
		  ```
