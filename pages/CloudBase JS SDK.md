- ## CloudBase JS SDK 是啥
	- CloudBase JS SDK **v3 版本** 已同时支持 **Web 浏览器** 和 **Node.js 服务端**  (所以 [[CloudBase Node SDK]] 已被弃用)
		- NPM 包名: `@cloudbase/js-sdk`
	- CloudBase JS SDK 用于访问 **Cloudbase 服务** .
- ## 文档
