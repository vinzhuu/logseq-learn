- ## 线程池的作用
	- 降低线程执行开销.
	  logseq.order-list-type:: number
		- 每次创建和回收线程, 都要从用户态切换到内核态, 进行系统调用, 开销较大 (占用 CPU 资源, 增大执行耗时).
		- ==线程池可以使用提前创建好的线程, 也不会在执行任务结束之后立即回收线程.==
	- 便于统一管理线程
	  logseq.order-list-type:: number
		- 维护线程执行状态, 维护任务执行状态.
		- ==分散在项目各处的 Thread 实例, 显然不好管理, 线程池就是集中维护了这些 Thread 实例==
	- 避免创建过量线程
	  logseq.order-list-type:: number
		- 开发人员可能会无意识过量线程, 导致资源耗尽.
		- ==线程的创建时机是由线程池决定, 开发人员提交任务时不会每次都创建线程==
