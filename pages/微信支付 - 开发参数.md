- ## 公共参数
	- 参考:
		- [mchid与appid申请](https://pay.weixin.qq.com/doc/v3/merchant/4012071573)
		  logseq.order-list-type:: number
		- [管理商户号绑定的APPID账号](https://pay.weixin.qq.com/doc/v3/merchant/4016328613)
		  logseq.order-list-type:: number
	- ---
	- 商户号 `mchid` .
	  logseq.order-list-type:: number
		- 提交资料申请, 申请成功后, 会有邮件通知 (包含 `mchid` 及其登录账号密码).
		- 包括 **普通商户** 和 **服务商** .
	- 应用 `appid` .
	  logseq.order-list-type:: number
		- 即 [[微信服务号]] / [[微信公众号]] / [[微信小程序]] / [[微信移动应用]] 这几种 **微信社交载体** (参见: [[微信开发: 概念]] )
		- 在 [商户平台 - AppID账号管理](https://pay.weixin.qq.com/index.php/extend/merchant_appid/mapay_platform/account_manage) 将指定 `appid` 关联到 **微信支付商户** .
			- `appid` 和 `mchid` 的主体必须一致.
- ## API 安全参数
	- ==如下所有参数, 都可在 [商户平台 - 账户中心 - API 安全](https://pay.weixin.qq.com/index.php/core/cert/api_cert#/) 设置.==
	- ### 商户 API 证书
		- #### 作用
			- APIv3 中, 用于调用所有接口.
			  logseq.order-list-type:: number
			- APIv2 中, 用于调用部分安全级别较高的接口.
			  logseq.order-list-type:: number
			- ==APIv3 与 APIv2 共用同一个==
		- #### 证书附件
			- `apiclient_cert.p12` : `p12` 格式证书文件
			  logseq.order-list-type:: number
			- `apiclient_cert.pem` : `pem` 格式证书文件
			  logseq.order-list-type:: number
			- `apiclient_key.pem` : 证书密钥文件.
			  logseq.order-list-type:: number
	- ### APIv3 参数
		- 商户 APIv3 密钥.
		  logseq.order-list-type:: number
		- 微信支付公钥.
		  logseq.order-list-type:: number
			- **微信支付** 用 **微信支付私钥** 签名;
			- **商户** 需要用 **微信公钥** 验签;
			- 以验证 **回调或响应** 确实来自 **微信支付** .
	- ### APIv2 参数
		- 参考: [APIv2 安全规范](https://pay.weixin.qq.com/doc/v2/merchant/4011985891)
		- 商户 APIv2 密钥
		  logseq.order-list-type:: number
			- 随机生成 32 个字符, 仅包含 "数字和大小写字母"
			  logseq.order-list-type:: number
			- ==关于修改 APIv2 密钥:==
			  logseq.order-list-type:: number
				- 一般是立刻生效, 少数情况有几分钟延迟.
				  logseq.order-list-type:: number
				- 修改后会同时存在两份密钥 ( ==或许微信的逻辑是新密钥校验不通过, 就使用旧密钥重试?== )
				  logseq.order-list-type:: number
				- 旧密钥会在 15 天后自动失效, 也可由用户提前作废 (但需要在新密钥生效的 24 小时之后)
				  logseq.order-list-type:: number
