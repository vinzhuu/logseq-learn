- ## 小程序框架提供的能力
	- 有如下能力:
		- 响应的数据绑定.
		  logseq.order-list-type:: number
			- 逻辑层修改数据，视图层会自动做相应的更新.
		- 页面管理.
		  logseq.order-list-type:: number
			- 管理所有页面的路由, 每个页面都有完整的生命周期.
		- 基础组件.
		  logseq.order-list-type:: number
			- **自带微信风格的样式以及特殊的逻辑** 的组件.
		- 丰富的 API
		  logseq.order-list-type:: number
			- 丰富的微信原生 API (如获取用户信息, 本地存储, 支付功能等)
