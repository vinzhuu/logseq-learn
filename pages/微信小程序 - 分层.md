- ## 逻辑层与视图层
	- ### 分层
		- 小程序的运行环境分成 **逻辑层** (App Service) 和 **视图层 (或称渲染层)** (View) .
	- ### 逻辑层介绍
		- `JavaScript` 运行在逻辑层:
		  logseq.order-list-type:: number
			- 逻辑层使用 **JavaScript 引擎** 为小程序提供:
				- **JavaScript 运行环境** 
				  logseq.order-list-type:: number
				- **微信小程序特有功能**
				  logseq.order-list-type:: number
		- 开发者写的所有代码最终将会打包成一份 `JavaScript` 文件, 并在小程序启动的时候运行, 直到小程序销毁.
		  logseq.order-list-type:: number
			- 这一行为类似 [[Service Worker]] , 所以逻辑层也称之为 App Service .
		-
		- ==注意：小程序框架的逻辑层并非运行在浏览器中, 因此 JavaScript 在 Web 中一些能力无法使用, 如 window，document 等. ==
	- ### 视图层介绍
		- `WXML` 和 `WXSS` 运行在视图层:
		  logseq.order-list-type:: number
			- [[WXML]] (WeiXin Markup language) 用于描述页面结构.
			  logseq.order-list-type:: number
				- 其中, `组件(Component)` 是页面结构的 **基本组成单元** .
			- [[WXSS]] (WeiXin Style Sheet) 用于描述页面样式.
			  logseq.order-list-type:: number
		- 另外, 由于在构建 `WXML` 页面时, 可能需要用到 JS 脚本:
		  logseq.order-list-type:: number
			- 但是, `WXML` 调用 JS 脚本构建页面, 可能会导致 **逻辑层** 和 **视图层** 之间的频繁通信.
			- 因此, 小程序引入了 [[WXS]] (WeiXin Script) 脚本语言, 用于帮助 `WXML` 构建页面, 避免了 **逻辑层** 和 **视图层** 之间的频繁通信.
			- ==不过随着微信小程序性能的增强, 貌似目前用的不多了, 暂时不用了解 (2026.06)==
- ## 线程
	- **视图层** 的界面采用 `WebView` 线程进行渲染.
		- 一个小程序可能有多个界面, 所以 **视图层** 可能存在多个 `WebView` 线程.
	- **逻辑层** 采用 `JsCore` 线程运行 JS 脚本.
		- **逻辑层** 只有一个线程.
- ## 层间通信
	- ### 层间借助 Native 通信
		- **视图层** 与 **逻辑层** 之间, 无法直接通信, 需要经由 微信客户端 (或称为 `Native` ) 中转.
		- 经由 `Native` 中转, **视图层** 与 **逻辑层** 可以有如下通信:
			- **逻辑层** 将 **数据** 进行处理后, 发送给 **视图层**, 同时接受 **视图层** 的 **事件反馈** .
			- **视图层** 接收 **逻辑层** 的数据, 反映成 **视图** , 同时将 **视图层** 的 **事件** 发送给 **逻辑层** .
		- **逻辑层** 发送网络请求也经由 `Native` 转发.
		- ![image.png](../assets/image_1742664723307_0.png){:height 576, :width 651}
	- ### 可 JSON 化
		- ==参考: AI==
		- 层间传递数据时, 会先将数据对象转为 JSON 字符串, 再传递.
		- 所以, 在 **逻辑层** 和 **视图层** 之间传递的数据, 需要保证它是 **可 JSON 化** 的.
		- 不可 JSON 化的数据:
			- 函数 (Function)
			  logseq.order-list-type:: number
			- Undefined
			  logseq.order-list-type:: number
			- 特殊对象:
			  logseq.order-list-type:: number
				- 如 RegExp（正则表达式）、Date（日期对象，会被转换成时间字符串）、Error 对象等.
			- 循环引用
			  logseq.order-list-type:: number
