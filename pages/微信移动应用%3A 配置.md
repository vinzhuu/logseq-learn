- ## 跳转/下载移动应用相关参数
	- 参考: [微信开放平台](https://open.weixin.qq.com/)  移动应用相关配置.
	- ### Android
		- [微信开放平台](https://open.weixin.qq.com/) -> 移动应用 -> 基础配置 -> 上架信息 -> Android 应用 -> **应用下载地址**
		  logseq.order-list-type:: number
	- ### iOS
		- [微信开放平台](https://open.weixin.qq.com/) -> 移动应用 -> 基础配置 -> 上架信息 -> iPhone 应用 -> **应用下载地址**
		  logseq.order-list-type:: number
		- [微信开放平台](https://open.weixin.qq.com/) -> 移动应用 -> 开发配置 -> iOS 应用 -> iPhone 应用 /  iPad 应用 -> **一个 Universal Links 与 一个备用 Universal Links**
		  logseq.order-list-type:: number
			- ==备用 Unversal Links 有效期仅为 3 个月, 且半年内仅可修改 2 次.==
			- Universal Links 要求:
				- 以 `https` 开头，以 `/` 结尾 .
				  logseq.order-list-type:: number
				- 建议带 `path` , 比如 `https://your_domain/app/` .
				  logseq.order-list-type:: number
			- 在实际调用 **微信 Open SDK** 时, 会校验传入的 **Universal Links** 是否与配置的  **Universal Links** 匹配.
