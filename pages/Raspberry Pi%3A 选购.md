		- 官方建议从 **授权经销商** 或 直接从 **树莓派官方** 购买树莓派, 以便在订单出现问题时获得支持.

- ## 如何购买树莓派
	- 进入树莓派产品列表: [Hardware](https://www.raspberrypi.com/products/)
	  logseq.order-list-type:: number
	- 选择产品, 进入产品详情.
	  logseq.order-list-type:: number
	- 点击 "Buy Now" , 选择型号和地区.
	  logseq.order-list-type:: number
		- 选择型号时, 主要查看都有哪些接口 (USB, 网口等).
	- 选择用途 (个人买家选择 Home 即可).
	  logseq.order-list-type:: number
		- 可以看到产品用途分为三类:
			- Home
			  logseq.order-list-type:: number
			- Industry
			  logseq.order-list-type:: number
			- Education
			  logseq.order-list-type:: number
		- ==只要型号一致, 应该就是同一产品, 用途无关紧要.==
			- 之所以区分用途, 可能是为了区分 **个人/企业/学校** 买家.
	- 点击 **授权经销商** 图标, 进入购买界面.
	  logseq.order-list-type:: number
		- 中国大陆地区, 推荐 [隽鹏数码专营店](https://junpengsm.tmall.com/) 和 **[开源硬件商城](https://shop105705408.taobao.com/)** 淘宝网店.
- ## 配件购买
	- ### 必需品
		- ==一般网购套餐会包含这些必需品==
		- 电源线 (power supply)
		  logseq.order-list-type:: number
		- 启动介质 (boot media)
		  logseq.order-list-type:: number
			- [[microSD Card]] (常用, 需要 microSD 读卡器)
			  logseq.order-list-type:: number
				- 如果 microSD 卡槽有插入 microSD , 树莓派将自动默认从 microSD 启动.
			- USB storage (如 USB [[SSD]] )
			  logseq.order-list-type:: number
			- [[Network Storage]]
			  logseq.order-list-type:: number
			- storage connected via a PCIe HAT (通过 PCIe HAT 连接的存储设备)
			  logseq.order-list-type:: number
			- ==需要看树莓派型号是否支持==
			- 参考: [Getting started - Boot media](https://www.raspberrypi.com/documentation/computers/getting-started.html#sd-cards)
	- ### 连接外设用的线缆
		- 网线
		  logseq.order-list-type:: number
		- 连接显示器的线缆
		  logseq.order-list-type:: number
	- ### 非必需品
		- 外壳.
		  logseq.order-list-type:: number
		- 散热风扇/散热金属片.
		  logseq.order-list-type:: number
- ## microSD 选购
	- 参考: [Getting started - Boot media](https://www.raspberrypi.com/documentation/computers/getting-started.html#sd-cards)
	- ### 容量下限
		- 对于安装 Raspberry Pi OS Lite , 至少 16G .
		- 否则, 至少 32G .
	- ### 容量上限
		- 对于如下设备, 不得超过 256G .
			- Raspberry Pi Zero
			  logseq.order-list-type:: number
			- Raspberry Pi 1
			  logseq.order-list-type:: number
			- early Raspberry Pi 2 models with the BCM2836 SoC
			  logseq.order-list-type:: number
		- 对于其他设备, 由于 [[MBR]] 的限制, 不得超过 2T .
	- ### 树莓派官方 SD Card
		- 参见: [Raspberry Pi SD Cards](https://www.raspberrypi.com/products/sd-cards/)
