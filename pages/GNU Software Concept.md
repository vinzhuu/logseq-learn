- ## 什么是 GNU Software
	- 即 [[GNU Project]] 支持下发布的软件, 也被称为 GNU Program 或 GNU Package.
	- 所有的 GNU Software 都必须是 Free Software
- ## GNU Software 的作者和版权
	- 大部分由 **志愿者** 编写, 一部分由 [[FSF]] 成员编写.
		- 一部分 **志愿者** 由公司或大学支付报酬.
	- 部分软件的版权归 FSF , 部分软件的版权归于它的 **贡献者** .
