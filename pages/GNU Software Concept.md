- ## 什么是 GNU Software
	- 即 [[GNU Project]] 支持下发布的软件, 也被称为 GNU Program 或 GNU Package.
	- 所有的 GNU Software 都必须是 Free Software
- ## GNU Software 的作者和版权
	- 大部分由 **志愿者** 编写, 一部分由 [[FSF]] 成员编写.
		- 一部分 **志愿者** 由公司或大学支付报酬.
	- 部分软件的版权归 FSF , 部分软件的版权归于它的 **贡献者** .
- ## GNU Software 的版权转让
	- GNU Software 的开发者可以:
		- 保留版权
		  logseq.order-list-type:: number
			- 开发者自己执行 (enforce) License.
		- 或将版权转让给 FSF .
		  logseq.order-list-type:: number
			- FSF 执行 (enforce) License .
	- FSF 只接受官方 GNU Software 的版权转让, 不接受其它软件的版权转让.
