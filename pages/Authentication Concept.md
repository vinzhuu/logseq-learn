- ## 什么是 Authentication
	- 参考: [Application Security With Apache Shiro](https://www.infoq.com/articles/apache-shiro/)  (Written By Shiro Founder: Les Hazlewood)
	- > Authentication (身份验证) 是验证用户身份的过程，即 **证明他们就是他们自称的那个人** 。这有时也被称为“登录”。
	- 这通常是如下步骤：
		- 收集用户的:
		  logseq.order-list-type:: number
			- 标识信息 (称为 `主体 principal` )
			  logseq.order-list-type:: number
			- 支持标识的证明 (称为 `凭据 credential` ).
			  logseq.order-list-type:: number
		- 向系统提交 **主体** 和 **凭据** .
		  logseq.order-list-type:: number
		- 系统验证用户提交的 **主体** 和 **凭据** :
		  logseq.order-list-type:: number
			- 如果 **凭据**  与系统对该用户 **标识 (主体)** 的期望匹配, 则认为该用户通过身份验证; 
			  logseq.order-list-type:: number
			- 如果它们不匹配, 则认为该用户未通过身份验证.
			  logseq.order-list-type:: number
	- 举个例子：
		- 常见示例是 `用户名/密码` 组合，用户通过提供他们的 `用户名(主体)` 和 `密码(凭证)` 登录到软件应用中。
		- 如果存储在系统中的 `密码 (或其表示形式)` 与 `用户指定的密码` 相匹配，则认为它们通过了身份验证。
- ## 对 Principal 的要求
	- 需要保证:  **同一时间** , 一个 `Principal` 只能在系统中确定唯一一个 **用户主体** .
- ## 用户唯一标识的种类
	- | 是否可变 | 具体类型 | 生成方式 | 是否允许修改 | 是否用于登录 | 非登录用途 | 典型示例 |
	  | ---- | ---- | ---- |
	  | 不可变唯一标识 | 存储主键或唯一键 | 系统生成 | 禁止修改 | 一般不用于登录, 因为通常不好记, 而且可能暴露系统底层细节 | 仅用于数据库存储、内部关联 | 自增主键、UUID、雪花 ID、自定义主键算法 |
	  | 不可变唯一标识 | 不可变展示 ID | 系统生成 或 用户自定义 | 禁止修改 | 一般不用于登录, 因为通常不好记 | 仅用于搜索用户、对外展示 | 小红书号 |
	  | 不可变唯一标识 | 不可变登录 ID | 系统生成 或 用户自定义 | 禁止修改 (为了降低复杂度) | 可用于登录 | 可用于搜索用户、对外展示 | QQ 号 |
	  | 可变唯一标识 | 可变展示 ID | 系统生成 或 用户自定义 | 允许修改 | 一般不用于登录 | 仅用于搜索用户、对外展示 | 微信号 |
	  | 可变唯一标识 | 可变登录 ID | 系统生成 或 用户自定义 | 允许修改 | 可用于登录 | 可用于搜索用户、对外展示 | GitHub 用户名 |
	  | 可变唯一标识 | 第三方系统 ID | 用户绑定 | 允许修改绑定 | 有些系统可用于登录, 有些系统不可用于登录 | 可用于关联第三方系统 | 生物信息 (指纹/掌纹/面容等), 身份证件 (身份证/护照等), 联系方式 (手机号/邮箱地址等), 社交媒体 (微信/微博/推特等) |
	- 对于 **第三方系统 ID** :
		- 必须是 第三方系统的 **不可变唯一标识** (而不能是 **可变唯一标识** ).
		  logseq.order-list-type:: number
			- 否则, 如果用户在 **第三方系统** 更改了这个 **可变唯一标识** , 那我们关联的 **唯一标识** 就失效了.
		- 某些系统关联的  **第三方系统 ID** , 可用于登录, 而某些系统可能只是用作 **关联第三方系统** , 而不用于登录.
		  logseq.order-list-type:: number
			- 比如: 政府的一些网站, 可以用 **身份证号** 登录 .
			- 比如: 微信/支付宝, 只是将 **身份证号** 用于关联 **实名系统** , 而不用于登录 .
	- ==一个用户系统, 可以同时存在多种 **唯一标识** .==
		- 但 至少需要一个 **不可变唯一标识** 和 一个 **登录 ID** (二者可以是同一个) .
