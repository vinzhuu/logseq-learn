- 直译: `随它而来的是……?`
- 含义: `是否可以由此推断……？`
- 例句:
	- > The program is free software. `Does it follow that` you can use it for any purpose?
	- 这个程序是自由软件。那么是否就能由此推断你可以将它用于任何目的？
- 摘录:
	- > If someone buys an exception to embed a program in a larger proprietary program, he's doing something wrong (namely, making proprietary software). `Does it follow that` the developer that sold the exception is doing something wrong too?
	  -- 引自 [GNU - Selling Exceptions to the GNU GPL](https://www.gnu.org/philosophy/selling-exceptions.html)
