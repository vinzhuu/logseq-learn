- ## 如何使用开放标签
	- 使用开放标签, 涉及如下两部分:
		- 使用 `<wx-open-xxx></wx-open-xxx>` , 声明这个标签.
		  logseq.order-list-type:: number
		- 在 `<script></script>` 中, 监听这个标签的事件.
		  logseq.order-list-type:: number
	- 代码示例:
		- ``` html
		  <wx-open-subscribe template="TenvU22BA1jCp4YHfYEpRuESXYReQyDuhs4vbdWA99I" id="subscribe-btn">
		    
		    <script type="text/wxtag-template" slot="style">
		      <style>
		        .subscribe-btn {
		          color: #fff;
		          background-color: #07c160;
		        }
		      </style>
		    </script>
		    
		    <script type="text/wxtag-template">
		      <button class="subscribe-btn">
		        一次性模版消息订阅              
		      </button>
		    </script>
		    
		  </wx-open-subscribe>
		  
		  
		  <script>
		  var btn = document.getElementById('subscribe-btn');
		    
		  btn.addEventListener('success', function (e) {            
		    console.log('success', e.detail);
		  });   
		    
		  btn.addEventListener('error',function (e) {             
		    console.log('fail', e.detail);
		  });
		  </script>
		  ```
- ## 声明开放标签 <wx-open-xxx>
	- ### 开放标签属性 (Attributes)
		- 开放标签属性分为两类:
			- 开放标签特有的属性
			  logseq.order-list-type:: number
				- 如 `appid` , `template`
			- HTML 标签通用属性
			  logseq.order-list-type:: number
				- 如 `id`
	- ### 开放标签插槽 (Slot)
		- #### 什么是插槽
			- **插槽** 就是 **开放标签** 允许我们 **自定义 (HTML 或 CSS)** 的地方.
				- **插槽** 由微信官方定义, 由开发者插入内容.
				- 每个插槽, 都有微信官方定义的名称.
			- 一个 **开放标签** 可能会有 **多个插槽** .
		- #### 如何声明插槽内容
			- 插槽内容, 使用 `<script type="text/wxtag-template" slot="xxx"></script>` 包裹.
			- 插槽内容:
				- 可以是 HTML
				  logseq.order-list-type:: number
				- 也可以是 CSS (在插槽内使用 `<style>` 标签包裹)
				  logseq.order-list-type:: number
				- 或是二者混合
				  logseq.order-list-type:: number
			- `slot` 属性:
				- `slot` 属性用于声明插槽的名称.
				  logseq.order-list-type:: number
				- 名称为 `defalut` 的插槽, 可以省略 `slot` 属性.
				  logseq.order-list-type:: number
			- ==注意: 插槽中的样式, 可以放心自定义, 不会影响外部页面.==
- ## 监听开放标签事件
	- 每个开放标签, 随着用户的操作, 会产生一些事件.
	- 可以通过如下代码, 监听开放标签的事件 (参见: [[Web Event Concept]] ):
		- ``` js
		  element.addEventListener('事件名称', function(e){})
		  ```
		- `e.detail` 为 事件的 **详细信息** .
- ## 布局定位
	- 与 **布局和定位** 相关的样式 (比如 `position: fixed; top -100;`):
		- 尽量不要声明在 **插槽内的元素** 上 .
		- 应声明在 **开放标签** 或 **开放标签** 的 **父元素** 上.
		- 这是为了避免布局和定位异常.
- ## CSP 配置
	- 对于有 [[Content Security Policy]] 要求的页面:
		- 需要添加白名单 `frame-src https://*.qq.com webcompt:`, 才能正常使用 **开放标签** .
