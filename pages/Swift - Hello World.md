- ## Print
	- ``` swift
	  print("Hello, world!")
	  
	  print("Hello, world, ", "Jack")
	  ```
- ## Semicolon
	- 除非你想在一行中编写多个语句，否则，分号不是必须的。
		- ``` swift
		  let cat = "🐱"; print(cat)
		  ```
