- ## 树莓派交互模式
	- ### 直接通过外设, 与树莓派交互
		- ==需安装带桌面的系统 (interactive computer with a desktop)==
		- 需要如下外设 (accessories):
			- 显示器
			  logseq.order-list-type:: number
			- 连接 树莓派 与 显示器 的线缆
			  logseq.order-list-type:: number
			- 键盘
			  logseq.order-list-type:: number
			- 鼠标
			  logseq.order-list-type:: number
	- ### 通过网络, 与树莓派交互
		- ==可以安装不带桌面的系统 (headless computer)==
		- 但在安装系统时, 需要预先配置:
			- hostname
			  logseq.order-list-type:: number
			- account
			  logseq.order-list-type:: number
			- network connection
			  logseq.order-list-type:: number
			- SSH
			  logseq.order-list-type:: number
