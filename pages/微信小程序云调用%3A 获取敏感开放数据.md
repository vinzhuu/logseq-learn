	- [[微信云开发 SDK: cloud.getWXContext()]]
	- 通过云函数获取开放数据时，可用此校验入参中的开放数据是否来自微信后台。
	- 此值类型为 string，有可能为空，JSON 字符串。解开之后的格式：
		- ```
		  {
		    keys: ['包含微信后台给的开放数据字段 1', '包含微信后台给的开放数据字段 2']
		  }
		  ```
